# FND-01 CI Implementation Plan

> **For agentic workers:** Apply this plan in small steps and record real verification results.

**Goal:** Make frontend and backend dependency restoration and build checks repeatable on every pull request.

**Architecture:** Keep the existing frontend pnpm lockfile. Generate NuGet lockfiles for all three .NET projects, then run each application's existing validation commands in separate GitHub Actions jobs.

**Tech Stack:** GitHub Actions, Node.js 24, pnpm 12.15.0, .NET SDK 10.

**Spec:** `docs/superpowers/specs/2026-10-28-foundation-design.md`; backlog FND-01.

## Constraints

- Do not initialize, commit, or push the repository; the user will create it.
- CI must not require a SQL Server service or production secrets for the current foundation tests.
- Do not run migrations on application startup.
