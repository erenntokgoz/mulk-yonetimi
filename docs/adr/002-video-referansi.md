# ADR 002 — Arayüz referansı

**Kabul edildi · 13 Kasım 2026**

Teknik Tasarım v1.1 §8 ve ilgili ARCH backlog maddeleri Vercel şablonuna görsel sadakat ister. Kullanıcının sonraki talimatı görsel kabul için videoyu referans alır.

Ekran görünümü, gezinme, akış ve animasyon video referansına göre doğrulanır. En arka katmandaki daireler kaldırılır. Türkçe metinler, klavye erişimi, mobil uyum ve gerçek API verisi proje kabul koşullarıdır.
